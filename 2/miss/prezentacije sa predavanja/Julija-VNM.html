Veštačke neuronske mreže u Juliji

Posmatra se neuronska mreža sa propagacijom signala unapred. Mreža je podeljena u slojeve neurona, gde svaki sloj sadrži niz neurona sa istom aktivacionom funkcijom. Tipične akvitacione funkcije su: linearna, sigmoidna, tangensni sigmoid, ReLU, itd.

Stoga će se na početku definisati takve funkcije i njihovi izvodi.

# Neke aktivacione funkcije i njihovi izvodi ...
sigmoid(Z) = 1 ./ (1 .+ exp.(-Z))
izvodSigmoid(O) = (O .* (1 .- O)) 

linear(Z) = Z
izvodLinear(O) = 1.0

tansig(Z) = tanh.(Z)
izvodTansig(O) = 0.5(1 .- O.*O);

Ovde je ulaz u aktivacionu funkciju vektor Z, dok se vrednosti izvoda aktivacione funkcije računaju na osnovu izlaza neurona O, radi bržeg izračunavanja. (U primeni, vrednost izlaza aktivacione funkcije se kešira i kasnije se koristi za računanje njenog izvoda.)

Nadalje, uvodi se struktura podataka da bi se opisao jedan sloj neurona.

mutable struct SlojNeurona
    W   # težine neurona
    b   # pragovi neurona
    aktivacionaFja
    izvodAktivacioneFje
    O   # izlazi sloja
    X   # ulazi u sloj
    dW  # promena težina
    db  # promena pragova
    vW  # inercija težina (kada se koristi momentum)
    vb  # inercija pragova (kada se koristi momentum)

    SlojNeurona(W, b, aktivacionaFja, izvodAktivacioneFje, O, X, dW, db, vW, vb) = new(W, b, aktivacionaFja, izvodAktivacioneFje, O, X, dW, db, vW, vb)
end

Polja uvedene strukture sadrže parametre mreže W i b koji će se kasnije podešavati njenom obukom. Pored toga, svaki sloj može imati drugačiju aktivacionu funkciju, te se ona i funkcija njenog izvoda takođe memorišu u strukturi. Algoritam za podešavanje parametera mreže će formirati korekcije parametara dW i db, dok su vW i vb pomoćne vrednosti gde se pamte inercijalne vrednosti za verziju algoritma sa momentum faktorom. Vektori ulaza u sloj X i izlaza iz njega Y se takođe memorišu kako bi realizacija koda bila jednostavnija (očiglednija). Treba primetiti da su izlazi jednog skrivenog sloja ujedno ulazi u naredni sloj, tako da se na iste vrednosti referiše iz susednih slojeva. Kako se ovde memorišu pokazivači na nizove, memorijsko zauzeće je beznačajno.

Inicijalizacija sloja neurona zahteva da se postavi broj neurona u sloju brojIzlaza i broj ulaza u sloj brojUlaza kako bi se inicijalizovali parametri sloja (mreže). Početne vrednosti sinapsi W se postavljaju na slučajne vrednosti, dok se početne vrednosti pragova b postavljaju na nule.

function SlojNeurona(brojUlaza::Int, brojIzlaza::Int, fja=linear, fjaIzvoda=izvodLinear)
    W = randn(brojIzlaza, brojUlaza)
    z = zeros(brojIzlaza, 1)
    X = zeros(brojUlaza, 1)
    return SlojNeurona(W, z, fja, fjaIzvoda, z, X, W, z, W*0, z)
end;

Računanje izlaza sloja neurona se sprovodi na osnovu ulaza u sloj X i na osnovu interno memorisanih parametara W i b. Pri tome se računa vrednost aktivacije Z (ulaz u aktivacionu finkciju), kao i izlaz iz sloja O. Te obe vrednosti se memorišu u sloju.

function izlaz(sloj::SlojNeurona, X)
    sloj.X = X
    Z = sloj.W * X .+ sloj.b
    O = sloj.aktivacionaFja(Z)
    sloj.O = O
    return O
end;

Ovde treba primetiti da je za računanje primenjana vektorizacija podataka, tj. jednim pozivom funkcije izlaz se izračunaju odzivi sloja neurona za sve elemente obučavajućeg skupa.

Struktura NeuronskaMreža modeluje celu neuronsku mrežu preko uređene kolekcije slojeva neurona. Stoga je jedino polje strukture kontejner slojeva nazvan slojevi.

struct NeuronskaMreža
    slojevi
    NeuronskaMreža(slojevi) = new(slojevi)
end;

Računanje izlaza mreže se dobija pozivom funkcije čiji su parametri: NeuronskaMreža čiji se odziv računa i ulazi u mrežu X. Kao i kod računanja izlaza sloja neurona, i ovde se više vektora ulaza može postaviti (po kolonama) u matricu X.

function izlaz(mreza::NeuronskaMreža, X)
    O = X
    for sloj in mreza.slojevi
        O = izlaz(sloj, O)
    end 
    return O
end;

Na osnovu izračunatih izlaza iz mreže i željenih (zadatih) izlaza fjaCilja računa ukupnu grešku, koja se minimizuje u procesu obuke neuronske mreže. Sam postupak obuke, zasnovan na Back propagation algoritmu (BP algoritam), iterativno ažurira vrednosti parametara mreže upotrebom izvoda (gradijenta) funkcije cilja po parametrima mreže. 

using Statistics

fjaCilja(Ymreza, Yzadato) = 0.5 * mean((Ymreza .- Yzadato).^2) 

izvodFjeCilja(Ymreza, Yzadato) = Ymreza .- Yzadato;

Kako se radi o izvodu složene funkcije, koriste se parcijalni izvodi funkcije cilja, izvodi aktivacionih funkcija (opisan funkcijom izvodFjeCilja) i ostali izvodi na osnovu kojih se računaju pomenuti gradijenti.

function gradijenti(sloj::SlojNeurona, dO)
    dZ = sloj.izvodAktivacioneFje(sloj.O) .* dO
    sloj.dW = dZ * (sloj.X')
    sloj.db = sum(dZ, dims=2)
    dO = (sloj.W') * dZ
    return dO 
end;

Iterativno ažuriranje vrednosti parametara (W i b) se vrši na osnovu gradijenata dw i db izračunatih funkcijom gradijenti.

function azurirajParametre(sloj::SlojNeurona, η, γ)
    if γ == 0.0
        sloj.W -= η * sloj.dW
        sloj.b -= η * sloj.db
    else
        sloj.vW = γ * sloj.vW .+ η * sloj.dW
        sloj.W -= sloj.vW

        sloj.vb = γ * sloj.vb .+ η * sloj.db
        sloj.b -= sloj.vb
    end
end;

Celokupan proces obuke neuronske mreže je opisan funkcijom obuka čiji su parametri:

  • mreza - promenljiva mreža, koja se obučava,

  • Xzeljeni, Yzeljeni - obučavajući skup sačinjen od parova ulaza i izlaza,

  • η - parametar BP algoritma - koeficijent brzine obučavanja,

  • γ - parametar BP algoritma - momentum faktor,

  • epsJ - granična (mala) vrednost funkcije cilja J kada se obuka završava,

  • maxEpoha - maksimalan broj epoha obuke (i tada se obuka prekida, ali željena funkcija cilja nije dostignuta),

  • prikazEpoha - broj epoha nakon kojih se pojavljuje kontrolni ispis.

function obuka(mreza::NeuronskaMreža, Xzeljeni, Yzeljeni, η, γ=0.0, epsJ=1e-6, maxEpoha=10000, prikazEpoha=1000)
    η /= size(Yzeljeni, 2)              # normalizacija momentum faktora
    Jovi = []                           # kontejner J vrednosti tokom obuke 
    
    for i = 1:maxEpoha
        Y = izlaz(mreza, Xzeljeni)              # odziv mreže
        J = fjaCilja(Y, Yzeljeni)       
        if J < epsJ
            push!(Jovi, J)
            break                               # mreža je obučena
        end

        dO = izvodFjeCilja(Y, Yzeljeni)         # računanje gradijenata
        for sloj in reverse(mreza.slojevi)      # ... unazad
            dO = gradijenti(sloj, dO)
        end
        for sloj in reverse(mreza.slojevi)      # ažuriranje parametara mreže
            azurirajParametre(sloj, η, γ)
        end

        if rem(i, prikazEpoha) == 0             # kontrolni ispis
            println("it: ", i, " J:", J)
        end
        push!(Jovi, J)
    end     
    return Jovi 
end;

Podela obučavajućeg skupa na nekoliko podskupova nije implementirana u funkciji obuka, već se ostavlja čitaocu da to doda u svojoj implementacijij.
